Policy brief opens in a new tab with a print/save-as-PDF action. The aggregated CSV holds 24 hourly rows; the variable table holds the recorded rows behind the heatmap, in the same schema as data/traffic_variables.csv so it can be re-imported.

Data note: every variable that pushes congestion is stored in data/traffic_variables.csv — one row per occurrence, carrying its category, location (lat/lng), time window, the traffic congestion level it is paired with, weight, confidence and source. The page fetches that file on load (falling back to an embedded seed copy when opened straight from disk), weights the heat layer with it, and states those rows as the reason for the congestion in each hotspot. Corridor geometry and the hourly congestion curve remain in this script (CORRIDORS, CONG). Schema: data/README-data-dictionary.md · regenerate: node tools/seed-variables-csv.mjs.
